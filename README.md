# Personal Expense Tracker

A C# application for tracking and managing personal expenses.

## Features

- Track daily expenses
- Categorize spending
- View expense reports and summaries
- Manage budgets

## Getting Started

### Prerequisites

- .NET Framework or .NET Core
- Visual Studio or Visual Studio Code

### Installation

1. Clone the repository:
```bash
git clone https://github.com/liewvk/PersonalExpenseTracker.git
```

2. Navigate to the project directory:
```bash
cd PersonalExpenseTracker
```

3. Build the project:
```bash
dotnet build
```

4. Run the application:
```bash
dotnet run
```
